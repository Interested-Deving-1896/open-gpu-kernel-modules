# open-gpu-kernel-modules

[![Built with Ona](https://ona.com/build-with-ona.svg)](https://app.ona.com/#https://github.com/Interested-Deving-1896/open-gpu-kernel-modules)

<!-- AI:start:what-it-does -->
This project provides the source code for NVIDIA's open GPU kernel modules on Linux. It enables developers and system integrators to build and install NVIDIA kernel modules, facilitating better integration with Linux systems. The project is used by developers working on custom kernels, system maintainers, and contributors to GPU-related infrastructure.
